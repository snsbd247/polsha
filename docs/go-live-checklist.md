# UAT, Parallel Run ও Go-Live চেকলিস্ট

সমিতির দায়িত্বপ্রাপ্তরা এই তালিকা ধরে সিস্টেম যাচাই করবেন। প্রতিটি ঘর শেষে টিক দিন, সমস্যা হলে নিচের **সমস্যার খাতা**-য় লিখুন।

সময়সূচি (প্রস্তাবিত):

| সপ্তাহ | কাজ |
|---|---|
| ১ | প্রস্তুতি + পুরোনো তথ্য Import + UAT |
| ২–৪ | Parallel Run — পুরোনো খাতা ও নতুন সিস্টেম পাশাপাশি |
| ৫ | Go-Live — শুধু নতুন সিস্টেম |

---

## ক. প্রস্তুতি (অ্যাডমিন)

- [ ] Settings → সাধারণ সেটিংস: সমিতির নাম (বাংলা/English), ঠিকানা, রেজি. নং, মোবাইল
- [ ] Settings → ব্র্যান্ডিং ও লোগো: লোগো, সভাপতির/ম্যানেজারের স্বাক্ষর, সিল, লেটারহেড, ফুটার, সদস্য কার্ডের নোট
- [ ] Settings → রশিদ সেটিংস: কাগজের মাপ, কপি সংখ্যা; একটি নমুনা রশিদ প্রিন্ট করে দেখা
- [ ] Settings → সিস্টেম পছন্দ: **চালুর তারিখ (Go-Live)**, ডিফল্ট ভাষা, নিষ্ক্রিয় লগআউটের সময়
- [ ] Settings → অর্থবছর, সিরিয়াল নম্বর, বিঘা = কত শতক
- [ ] এলাকা ও মৌজা, জমির ধরন, সেচের ধরন, মৌসুম, সেচের রেট, ঋণের প্ল্যান
- [ ] ব্যাংক হিসাব; Chart of Accounts-এ দরকারি উপ-হিসাব
- [ ] প্রতিজন কর্মীর ইউজার, সঠিক Role; অপ্রয়োজনীয় ইউজার নিষ্ক্রিয়
- [ ] SMS গেটওয়ে — নিজের মোবাইলে পরীক্ষামূলক SMS
- [ ] Settings → লাইসেন্স ও ইনস্টলেশন: লাইসেন্স "বৈধ", শেষ ব্যাকআপ আজকের, শিডিউলার "চলছে"

## গ. UAT — প্রতিটি Role দিয়ে আসল কাজ

প্রতিটি Role-এর ইউজার দিয়ে নিজে করুন (অ্যাডমিন দিয়ে নয়)। ফল ঠিক হলে ✔।

| Role | পরিস্থিতি | প্রত্যাশিত ফল | ✔ |
|---|---|---|---|
| ডাটা এন্ট্রি | নতুন কৃষক, একই NID দিয়ে আবার | দ্বিতীয়বার আটকায় | ☐ |
| সদস্য কর্মকর্তা | সদস্যপদ আবেদন → Manager → President | সদস্য নম্বর তৈরি, কার্ড প্রিন্ট | ☐ |
| সদস্য কর্মকর্তা | জমি যোগ, বর্গা, হস্তান্তর | জমির ইতিহাসে সব ধাপ | ☐ |
| সেচ কর্মকর্তা | নতুন রেট → অনুমোদন → Bulk ইনভয়েস | প্রিভিউ = ইনভয়েসের মোট | ☐ |
| ক্যাশিয়ার | আংশিক সেচ আদায়, রশিদ প্রিন্ট | বকেয়া কমে, রশিদে বাকি বকেয়া | ☐ |
| ক্যাশিয়ার | একত্রিত পেমেন্ট | ঋণ → সেচ → শেয়ার → সঞ্চয় ক্রমে ভাগ | ☐ |
| ক্যাশিয়ার | রশিদ বাতিলের আবেদন → Manager অনুমোদন | বকেয়া ফিরে আসে, রশিদে "বাতিলকৃত" | ☐ |
| ক্যাশিয়ার | দিন শেষে মিলকরণ, তারপর নতুন আদায় | বন্ধ দিনে আটকায় | ☐ |
| ক্যাশিয়ার | অনলাইন পেমেন্ট যাচাই | রশিদ ও SMS যায় | ☐ |

| ঋণ কর্মকর্তা | সীমার বেশি ঋণ, জামিনদার নিজে | দুটোই আটকায় | ☐ |

| হিসাবরক্ষক | ব্যাংক মিলকরণ, মাস বন্ধ | বন্ধ মাসে এন্ট্রি আটকায় | ☐ |

## ঘ. Parallel Run (২–৪ সপ্তাহ)

প্রতিদিন পুরোনো খাতা ও সিস্টেম — দুই জায়গাতেই লেখা হবে।

**প্রতিদিন (ক্যাশিয়ার + হিসাবরক্ষক)**
- [ ] দিনের মোট আদায় (খাতভিত্তিক) খাতা = সিস্টেমের দৈনিক মিলকরণ
- [ ] হাতে নগদ = খাতার নগদ জের
- [ ] রশিদ বইয়ের নম্বর — Receipt Serial Admin-এ ফাঁক বা ডুপ্লিকেট নেই

**প্রতি সপ্তাহে (ম্যানেজার)**
- [ ] সেচ বকেয়া, সঞ্চয়, শেয়ার, ঋণের মোট — খাতা = সিস্টেম
- [ ] লেজার সঠিকতা ও উৎস বনাম খতিয়ান — পার্থক্য ০
- [ ] সমস্যার খাতার সব বিষয় সমাধান হয়েছে

**Go-Live-এর শর্ত:** টানা ১০ কর্মদিবস খাতা ও সিস্টেমে কোনো অমিল নেই, আর সমস্যার খাতায় কোনো খোলা "জরুরি" বিষয় নেই।

## ঙ. Go-Live দিন

- [ ] আগের দিনের শেষে সব খাতার সমাপনী জের লিখে সভাপতি ও ম্যানেজারের স্বাক্ষর
- [ ] Settings → সিস্টেম পছন্দ: চালুর তারিখ চূড়ান্ত
- [ ] একটি হাতে-চালানো ব্যাকআপ (Admin → ব্যাকআপ) ডাউনলোড করে অফিসের বাইরে রাখা
- [ ] পুরোনো খাতায় লাল কালিতে "… তারিখ থেকে সফটওয়্যারে" লিখে বন্ধ
- [ ] সব কর্মী নিজের পাসওয়ার্ডে লগইন করে দেখেছেন; সাধারণ/শেয়ার করা পাসওয়ার্ড নেই
- [ ] প্রথম সপ্তাহ প্রতিদিন বিকেলে ম্যানেজার ড্যাশবোর্ড ও দৈনিক মিলকরণ দেখবেন

## চ. নিরাপত্তা ও রক্ষণাবেক্ষণ (নিয়মিত)
